## 已接通

- 首页：真实商品、分类、SKU 数、按批次成本统计的库存总值、低库存与 30 天内有效期预警；保存后刷新。
- 商品：在“添加商品”中新增资料；详情供应商字段进入资料编辑，支持名称、SKU、分类、单位、规格、货位、供应商、安全库存。存量成本只能通过库存单据变化。
- 入库：多商品、最多三位小数数量、成本单价、批次有效期、供应商、日期、运费、付款方式记录、草稿保存及恢复。
- 出库：多商品、领用/报废/退供应商/内部使用分类、备注、先进先出扣减；不足库存整单失败。
- 盘点：全部/未盘/有差异筛选、实盘数量（支持零）、暂存恢复、提交差异单；并发变化拒绝提交，刷新受影响商品后要求重新盘点。
- 详情：真实批次、出入库流水及类型筛选；进入入库/出库时带入当前商品。
- 成本预览由 `inventory_quote` 后端计算，最终提交在事务内重新计算，避免以客户端金额记账。

## 接口与安全

`merchant-v1` 动作：`inventory_list`、`inventory_get`、`inventory_create`、`inventory_update`、`inventory_draft`、`inventory_quote`、`inventory_document`。

所有动作通过 `storeFor` 验证当前门店。数据库表启用 RLS，客户端只有所属门店读取权限，写入及成本规则由云函数调用受限数据库函数执行。整单提交对商品按 ID 顺序加锁；批次扣减、库存、流水、单据状态原子提交。单据 UUID 是持久幂等键，网络重试不会重复入出库；草稿用 revision 防覆盖，盘点用商品 version 防覆盖。

迁移顺序：`202611030003_inventory.sql` → `202611030004_inventory_documents.sql`，然后部署 `merchant-v1`。第二个迁移将库存升级为小数、引入整单与批次，并禁用第一版单商品变更函数的调用权限。

## 仍依赖其他模块的动作

- 扫码：需要相机/条码识别入口及条码查询；当前引导手动选择商品。
- 送货单/发票附件：需要 Storage 策略和附件接口，不保留看似已上传的本地图片。
- 同步开支：已由开支迁移接通，勾选后随入库事务记账，盘亏自动记录损耗；挂账生成待支付记录，其他付款方式记录为已支付，不发起支付。凭证可在开支详情中编辑补充。
- 关联工单与技师领料：需工单材料成本及员工领料授权接口；不拿收款订单冒充施工工单，不把基础技师名单冒充授权流程。

对应调用点保留 TODO 或明确未接通反馈，不影响独立库存提交。

## 入库单价与数量（设计稿 StockInPrice / StockInPriceZero / StockInPriceNote）

- 明细里的「单价」是带笔形图标的灰色块，点击弹出「修改单价」底部弹层：数字键盘、两位小数，快捷项「上次进价」「商品成本价」，实时显示「数量 × 单价 = 小计」。
- 默认单价：最近一次入库批次的单价（`inventory_read` 返回的 `last_cost`，迁移 `202611190001_inventory_last_cost.sql`）；没有入库记录取商品成本价；都没有（含成本为 0）留空，显示「请输入」，不显示 ¥0.00。
- 单价留空时弹层「确定」不可点，提交入库前页面也会拦截；保存草稿允许单价留空（`inventory_document` 在 `post=false` 时接受 `cost: null`）。
- 单价为 0 允许确认：弹层出现橙色提示，按钮改为「确定，按赠品入库」，该行标「赠品」，批次成本记 0。
- 数量是输入框，加减保留；须大于 0、最大 9999，不允许小数的商品只能填整数；服务端同样校验。
- 商品的 `cost`（成本价）是现存批次的加权平均，不是上次进价；设计稿“待确认”的成本价口径沿用这个现状。

## 入库运费（设计稿 StockInFreight / StockInFreightNote）

- 入库页「费用」里点「运费」整行，弹出「运费」底部弹层：数字键盘、两位小数，默认 ¥0.00（留空按 0），不能为负，最大 99999.99（客户端与 `inventory_rules.ts` 都校验）。
- 快捷项：「无运费」清零；「上次 ¥120.00」是同一供应商最近一次已入库单据的运费（`inventory_last_freight`，只读），没有记录不显示。
- 「运费计入商品成本」开关默认关闭，payload 字段 `freight_to_cost`。关闭：运费只进应付合计；打开：提交入库时由数据库把运费按各商品金额占商品合计的比例摊入各批次成本（迁移 `202611190002_inventory_freight_to_cost.sql`，`inventory_allocate_freight`），批次单价 = 入库单价 + 分摊运费 ÷ 数量，单价为 0 的赠品不分摊。批次单价只有两位小数，向下取整后的尾差记在单据运费里，保证 `total`（应付合计）仍等于 商品合计 + 运费。
- 应付合计、底部应付金额、「同步记一笔开支」的金额都包含运费，开支金额等于应付合计。单据保留页面提交的单价和运费，不显示摊销后的单价；草稿原样保存，不分摊。
- 弹层底部实时显示「商品合计 + 运费 = 应付合计」（商品合计取服务端报价）；点「确定」回写入库页，运费行右侧在打开开关且运费大于 0 时显示「计入成本」小标签；点遮罩不保存。
- 修正：保存草稿时入库单价可以留空，`documentError` 现在对草稿放行空单价（此前只放宽了提交前的检查，草稿仍会被拒绝）。
- 测试：`supabase/tests/inventory_freight.sql`（`inventory_freight.mjs`）、`inventory_rules.test.ts`、`test/stock_in_freight_test.dart`。

## 出库：关联工单、领用技师、损耗报废、退回供应商（设计稿 StockOut / StaffPicker / WorkOrderPicker / StockOutPickerNote / StockOutScrap / StockOutReturn）

- 出库类型是四个互斥标签（组件库 `AppChoiceGroup`）。**施工领用 / 内部使用** 是基础版式（关联信息、出库明细、领用成本、备注）；**损耗报废**、**退回供应商** 各有自己的版式，仍是同一张出库单（`payload.reason`）。
- 关联工单：只列进行中的工单（客户已到店、尚未完成的预约），按到店时间倒序，行内「车牌 · 服务项目 · 技师 · 到店时间」，搜索按车牌，右上角「清除」。选中后「领用技师」自动带入该工单的技师（可再改），清除工单不清技师。出库单保存 `workorder_id`（预约 id，数据库校验归属本店）和由数据库生成的显示文字 `workorder`（迁移 `202611190003`）。历史单据的 `order_id` 仍可显示。
- 领用技师（通用「选择技师」弹层，设计稿说明新建预约的技师也复用它）：姓名、擅长项目、空闲 / 施工中（有进行中的工单即「施工中」，只作提示，仍可选），搜索按姓名，已停用的不显示。数据来自 `inventory_assignments`（`technicians` / `workorders`）。
- 「本次领用成本」副标题：关联了工单写「将计入该工单的成本核算」，没有关联写「未关联工单，仅记录出库成本」。**TODO**：按工单汇总成本的核算页面还没有，目前只在出库单上记录关联的工单。
- 损耗报废：报废原因（过期 / 破损 / 受潮变质 / 其他，默认破损，`payload.scrap_reason`）、备注、出库商品、报废成本；提交时必须有报废原因。
- 退回供应商：供应商必选（必须是本店已有供应商，服务端校验）、应退金额（`payload.refund_amount`，仅作记录）、出库商品。**TODO**：设计稿的「同步记一笔退款开支」要写负数开支，而开支目前只支持大于 0 的金额，所以这个开关明确显示「暂未开放」，点击提示原因，不假装成功；设计稿的「指定批次」也暂不支持，出库仍按先进先出扣减。
- 这两种版式没有「取消」按钮（设计稿只有一个「确认出库」），左上角仍是关闭按钮。

### 退回供应商：同步退款开支（迁移 `202611190004_expense_refund.sql`）

- 退回供应商的出库单提交时，若 `payload.sync_expense = true` 且 `refund_amount > 0`，数据库触发器 `inventory_expense_sync` 生成一笔**负数开支**：金额 −应退金额，分类「材料采购」（冲减本月材料采购和预算占用），往来方为供应商，状态已付款，备注默认「退回供应商退款」。应退金额为 0 或没开同步不生成；其他出库类型不生成。
- 负数只允许由库存单据同步生成：`expense_entries` 约束改为 `amount <> 0 and (amount > 0 or source_document is not null)`；手工记账 / 编辑仍必须大于 0（`invalid_amount`）。同步生成的开支仍是锁定的，作废出库单时一起撤销。退款是减少支出，不受预算上限拦截。
- 开支页面：列表和详情里退款显示绿色「+¥80.00」，支出仍是「−¥120.00」；日合计、分类合计按净额计算。
- 出库页（退回供应商版式）的「同步记一笔退款开支」开关默认打开，副标题随应退金额显示「在开支里记 -1,280 元」。
