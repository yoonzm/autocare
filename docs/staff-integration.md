# 员工模块接入（员工与权限）

用户已批准把员工模块的全部页面接入真实后端：员工列表 / 新增 / 编辑 / 详情、邀请、角色权限、提成方案、施工记录、停用 / 转交 / 启用、已停用详情。界面以设计稿为视觉基线，生成页位于 `apps/merchant/lib/pages/gen/` 不手工修改；接后端的模板由 `apps/merchant/tools/bind_staff.py` 从生成页派生（只替换数据来源与事件，视觉保持原样）。

## 保持不变的界面

12 张设计稿页面的结构、文案、颜色与交互布局保持原样（已用 Chromium 设计稿截图与 Flutter 渲染逐页比对）。两处按最新设计稿修正了生成页过期的颜色：员工列表右上角「+」、邀请页「完成」为主色蓝底。

## 真正接通的动作（`merchant-v1` 的 `staff_*`，迁移 `202611090001_staff.sql`）

| 动作 | 说明 |
| --- | --- |
| `staff_list` / `staff_get` | 员工列表（含角色人数、本月台次、施工状态、邀请状态）、员工详情（本月提成、最近施工、进行中订单、各服务项目提成） |
| `staff_save` | 新增 / 编辑员工：角色（店长 / 前台收银 / 施工技师）、手机号唯一、擅长项目、固定工位、入职日期。技师同步写入预约排班资源，预约逻辑不变；原 `appointment_resource_save` 不再接受技师 |
| `staff_status` | 停用 / 启用。停用技师若有进行中或待到店的预约，必须同时指定接手技师（`transfer_to`），事务内转交并复核时段冲突；停用后排班资源同步停用，历史记录与提成保留；记录操作人与时间 |
| `staff_commission_save` | 提成方案：跟随项目 / 统一比例 / 按项目自定义。仅对之后完工的订单生效 |
| `staff_records` | 施工记录（本月 / 上月 / 全部）：台次、提成、平均用时、明细 |
| `staff_permissions_save` | 逐店保存前台收银、施工技师的权限开关；店长固定为全部；数据库提供 `staff_has_permission(store, role, permission)` 供员工端和后续接口复用 |
| `staff_invite` | 生成 7 天有效的邀请令牌（只存 SHA-256），返回邀请链接；重新生成会作废旧邀请 |

提成：服务项目新增结构化提成（`commission_type` 比例 / 固定、`commission_value`）；既有项目与新建项目按描述里的“提成 8%”“提成 ¥60/单”解析一次。预约订单结算（回填 `orders.appointment_id`）时由触发器按当时规则写入 `staff_commissions` 快照，之后改规则不重算；比例按实收（扣除会员折扣后的占比），固定金额按数量。仅预约结算的订单有施工技师；无预约的散客开单没有技师归属，不产生提成。

## 仍为 TODO / 未接通

- **员工端登录与激活**：员工端小程序（`apps/staff-mini`）尚未创建。`staff_activate`（校验令牌哈希与手机号，写 `activated_at`、置 active）待员工端实现；在此之前新增员工保持「待激活」。
- **短信邀请**：缺少助通的邀请短信模板与通知类发送接口，`staff_invite` 的 `via: 'sms'` 明确返回未接通，不返回假成功。预期接口：`SmsProvider.sendNotice`。
- **邀请链接**：需要配置 `STAFF_INVITE_BASE_URL`（https）；未配置时明确提示，不生成不可用链接。
- **提成方案「统一比例」「按项目自定义」**：设计稿没有画比例输入界面，页面点击只提示 TODO；后端接口已支持，待界面确认后接入。
- **服务项目编辑页的「技师提成」**：现有设计页仍显示“此设置暂未接通”，需在服务项目模块单独接入；在此之前提成来自描述解析或接口。
- 客户好评、施工进度百分比、今日休息状态没有数据来源，页面显示「—」或不显示，不造假。
- 员工名额上限（套餐 `staff_limit`）暂不在保存时校验，后台员工数仍显示「—」。
- 邀请过期后的「重新发送」入口：设计稿的员工详情没有画该控件；邀请页的「复制邀请链接」会重新生成邀请，详情页入口待设计。
- 员工详情页的「角色与权限」只跳转到权限页，不单独授权某个人。

## 部署顺序与验证

1. 先执行 `202611090001_staff.sql`（迁移会把既有预约技师回填为员工），再部署 `merchant-v1`，最后发布客户端；缺一时前端显示错误和重试，不回退示例数据。
2. 配置 `STAFF_INVITE_BASE_URL` 后才能复制邀请链接。
3. SQL：`supabase/tests/staff.sql`（权限、事务、转交、提成快照、RLS）；规则：`staff_rules.test.ts`；前端：`test/staff_live_test.dart`、`test/staff_ui_test.dart`。
