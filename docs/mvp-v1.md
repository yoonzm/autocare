# 一期 MVP 范围(限时免费、无会员端、无线上支付)

目标:不丢核心功能,先快速上线。一期只发布**商户端 App**(老板与员工同一个 App),通过收缩发布范围实现,不重写、不删除已有代码。

## 发布范围

| 端 | 一期 |
| --- | --- |
| 商户端 Flutter App(老板 + 员工) | 上线,唯一交付物 |
| 会员端小程序 `apps/member-mini` | 不发布。`member-v1` 云函数保留,不对外承诺 |
| 店员端小程序 / 桌面端 | 不做(员工已并入商户端) |
| 运营后台 `apps/admin` | 仅内部使用:开账号、查短信、注销账号、套餐配置 |

## 一期包含

**老板侧**
- 注册 / 登录 / 忘记密码 / 账号注销(短信用助通真实渠道)
- 服务项目、会员卡种、次卡套餐、工位与营业时间、新店默认模板
- 会员与车辆、车牌扫码找会员
- 预约(商家代客创建、改约、取消、日程)
- 开单与收银(选择服务;会员卡、储值、次卡抵扣)
- 库存:商品、入库、出库、盘点、供应商(与开单无关联:订单明细只关联服务,开单不扣库存)
- 支出:记账、分类、预算、分摊
- 首页与基础经营统计
- 员工档案、角色、角色权限、提成方案、施工记录、停用 / 转交 / 启用

**员工侧(需独立可用)**
- 手机号验证码登录、选择身份、加入门店
- 技师:工作台、任务、更新进度、完工提交、业绩提成、消息
- 前台:今日到店、预约、预约结算
- 权限由 `merchant-v1` 的 `staff_gate.ts` 逐请求校验

## 无线上支付的处理

- 收银只记录客户的支付方式(现金、微信收款码、支付宝、刷卡),由商家线下收款,系统只记账。
- 会员充值、办卡、买次卡同样为线下收款后录入。线上充值仍为 TODO 并明确阻止,不返回假成功。
- 不出现支付进件、收款配置、发票、退款到账等页面入口。

## 限时免费

在套餐配置增加"限时免费"开关,按套餐版本生效,由运营后台控制,不配置截止日期。

- 开关打开:`subscription_catalog` 返回实付金额 0 与免费标识;订阅页价格显示 ¥0 并带"限时免费"标识(可保留原价划线),界面结构不变。
- `subscription_simulate` 照常创建订单与权益,金额记 0,订单来源标为"限时免费",不再标"模拟支付",不计入收入。
- 开关关闭:恢复原价。已有订阅保留到期时间。
- 待定:免费订阅是否仍开放 1 / 3 / 12 个月全部周期(默认开放)。
- 接入真实支付时,关闭开关即可。AGENTS 中"模拟支付"例外仅适用于付费订阅,本功能不依赖它。

## 一期新增开发

1. 限时免费开关(后台套餐配置、`subscription_catalog` / `subscription_simulate`、订阅页展示)。
2. 员工端会员简况与扫码找会员:需要后端脱敏查询接口,核销需车主确认。
3. 员工邀请页二维码:接下载链接生成真实二维码,否则一期隐藏二维码。
4. 修改密码(商户端与员工端)。

## 一期暂缓并隐藏(需逐项批准)

隐藏入口属于界面改动,按 AGENTS 约束必须先取得批准。前端用统一的一期开关控制入口,路由与页面代码不删除;关键规则在云函数拦截(套餐功能标志设为 off),不只靠隐藏入口。

- 多门店切换与新增门店
- 消息通知、短信营销、优惠券
- 数据备份、导出
- 会员跟进、回访、挂单、反馈(待确认)
- 支付进件、收款配置、发票
- 会员端小程序入口

## 节奏

- 第 1 周:冻结范围,批准隐藏清单,落地一期开关、套餐功能标志、限时免费。
- 第 2 周:新增开发(员工端会员简况与扫码、修改密码、邀请二维码);走通"注册→建服务→录会员车辆→预约→开单→库存与支出→员工完工与结算"全流程并补自动化测试;并行办签名、短信模板、商店资料。
- 第 3 周:3 到 5 家真实门店内测,修阻塞项,提审。
- 范围冻结后,新需求一律进二期清单。
